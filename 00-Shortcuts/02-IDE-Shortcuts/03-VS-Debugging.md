# Visual Studio - Debugging

Keyboard shortcuts for debugging in Visual Studio.

## Run & Debug

| Action | Shortcut |
|--------|----------|
| Start Debugging | F5 |
| Start Without Debugging | Ctrl+F5 |
| Stop Debugging | Shift+F5 |
| Restart | Ctrl+Shift+F5 |
| Attach Debugger | Ctrl+Alt+P |

## Breakpoints

| Action | Shortcut |
|--------|----------|
| Toggle Breakpoint | F9 |
| Disable Breakpoint | Ctrl+F9 |
| Clear All Breakpoints | Ctrl+Shift+F9 |
| Breakpoints Window | Ctrl+Alt+B |

## Stepping

| Action | Shortcut |
|--------|----------|
| Step Into | F11 |
| Step Over | F10 |
| Step Out | Shift+F11 |
| Run to Cursor | Ctrl+F10 |
| Continue | F5 |

## Windows & Views

| Action | Shortcut |
|--------|----------|
| Locals | Ctrl+Alt+V, Ctrl+L |
| Watch | Ctrl+Alt+W, (1-4) |
| Call Stack | Ctrl+Alt+C |
| Threads | Ctrl+Alt+H |
| Modules | Ctrl+Alt+U |
| Immediate | Ctrl+Alt+I |
| Output | Ctrl+Alt+O |

## Inspection

| Action | Shortcut |
|--------|----------|
| Quick Watch | Ctrl+Alt+Q |
| DataTips | Hover over variable |
| Evaluate in Console | Ctrl+Alt+I |
| Debug Output | Ctrl+Alt+O |

## Conditional Debugging

| Action | Shortcut |
|--------|----------|
| Set Breakpoint Condition | F9, then right-click |
| Set Hit Count | Right-click breakpoint |
| Set Tracepoint | Right-click breakpoint |
| Add Watch | Right-click variable |
