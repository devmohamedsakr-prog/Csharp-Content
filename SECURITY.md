# Security Policy

## Supported Versions

We try to keep our code and examples up to date with the latest LTS (Long Term Support) versions of .NET. Security updates will only be applied to the main branch.

## Reporting a Vulnerability

Please **do not report security vulnerabilities through public GitHub issues**.

If you believe you have found a security vulnerability in this repository, please report it privately. You can do this by using the "Security" tab on the GitHub repository and clicking "Report a vulnerability" (if enabled), or by contacting the repository owner directly.

We appreciate your efforts to responsibly disclose your findings, and we will make every effort to acknowledge your report and fix the issue promptly.
