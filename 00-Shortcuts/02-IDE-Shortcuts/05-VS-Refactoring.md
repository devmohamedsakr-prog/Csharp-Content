# Visual Studio - Refactoring

Keyboard shortcuts and quick actions for refactoring in Visual Studio.

## Quick Actions & Refactorings

| Action | Shortcut |
|--------|----------|
| Quick Actions | Ctrl+. |
| Extract Method | Ctrl+M, Ctrl+M |
| Rename | Ctrl+R, Ctrl+R |
| Organize Usings | Ctrl+R, Ctrl+G |
| Remove Unused Usings | Ctrl+R, Ctrl+U |

## Formatting & Cleanup

| Action | Shortcut |
|--------|----------|
| Format Document | Ctrl+K, Ctrl+D |
| Format Selection | Ctrl+K, Ctrl+F |
| Remove & Sort Usings | Ctrl+R, Ctrl+G |
| Make Private | Ctrl+R, Ctrl+P |
| Add Braces | Ctrl+K, Ctrl+B |

## Common Quick Actions

| Action | Shortcut | Available for |
|--------|----------|---------------|
| Generate Class/Interface | Ctrl+. | New types |
| Generate Field | Ctrl+. | Properties |
| Add null check | Ctrl+. | Parameters |
| Add braces | Ctrl+. | Single line statements |
| Convert to expression body | Ctrl+. | Properties/methods |
| Inline variable | Ctrl+. | Local variables |

## Preview & Compare

| Action | Shortcut |
|--------|----------|
| Preview Changes | Click preview button |
| Show Refactoring Preview | See changes before applying |

## Tips

- Use `Ctrl+.` frequently - it provides context-aware quick actions
- Light bulb icon indicates available refactorings
- Red squiggle = errors with quick fixes available
- Yellow squiggle = warnings with suggestions
