## Quick Decision Guide

| Need | Use |
|------|-----|
| Simple condition | if |
| Multiple options | switch |
| Many iterations | foreach |
| Specific count | for |
| Condition-based | while |
| At least once | do-while |
| Exit early | break |
| Skip iteration | continue |
| Exit method | return |
