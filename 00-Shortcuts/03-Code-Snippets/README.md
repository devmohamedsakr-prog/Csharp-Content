## 💡 How to Use

### Visual Studio / VS Code
1. Type the snippet shortcut (e.g., `prop`)
2. Press **Tab** or **Enter** to expand
3. Use **Tab** to navigate through placeholders
4. Type to replace placeholders

### Example
```
Type: prop
Press: Tab
Result:
public int MyProperty { get; set; }
        ↑ cursor here - edit name
```

## 🎯 Most Common Snippets

| Shortcut | Generates | How to Use |
|----------|-----------|-----------|
| `prop` | Auto-property | Type `prop` + Tab |
| `propfull` | Full property with backing field | Type `propfull` + Tab |
| `ctor` | Constructor | Type `ctor` + Tab |
| `class` | Class declaration | Type `class` + Tab |
| `for` | For loop | Type `for` + Tab |
| `foreach` | Foreach loop | Type `foreach` + Tab |
| `if` | If statement | Type `if` + Tab |
| `try` | Try-catch block | Type `try` + Tab |
| `method` | Method declaration | Type `method` + Tab |

## 🔍 Finding All Snippets

### Visual Studio
- **Tools** → **Code Snippets Manager** (Ctrl+K, Ctrl+B)
- Or type snippet and IntelliSense shows available options

### VS Code
- **File** → **Preferences** → **User Snippets**
- Or install extensions for more snippets
