# Visual Studio - Navigation

Keyboard shortcuts for navigating in Visual Studio.

## File Navigation

| Action | Shortcut |
|--------|----------|
| Open File | Ctrl+O |
| Go to File | Ctrl+Shift+T |
| Solution Explorer | Ctrl+Alt+L |
| Open Recent | Ctrl+Alt+T |
| Quick Open | Ctrl+P |

## Code Navigation

| Action | Shortcut |
|--------|----------|
| Go to Definition | F12 |
| Peek Definition | Alt+F12 |
| Go to Implementation | Ctrl+F12 |
| Find All References | Shift+F12 |
| Navigate Back | Alt+← |
| Navigate Forward | Alt+→ |

## Symbol Navigation

| Action | Shortcut |
|--------|----------|
| Go to Line | Ctrl+G |
| Go to Member | Ctrl+M, Ctrl+G |
| Goto Type | Ctrl+T |
| Find Symbol | Ctrl+Alt+F12 |

## View Navigation

| Action | Shortcut |
|--------|----------|
| Error List | Ctrl+\\, Ctrl+E |
| Output | Ctrl+Alt+O |
| Properties | F4 |
| Toolbox | Ctrl+Alt+X |
| Server Explorer | Ctrl+Alt+S |

## Bracket Navigation

| Action | Shortcut |
|--------|----------|
| Match Brace | Ctrl+] |
| Expand Selection | Shift+Alt+= |
| Shrink Selection | Shift+Alt+- |
