# Advanced C# Features

Explore advanced language features that enable cleaner, more expressive code.

## Topics Covered

- **Generics**: Generic classes, methods, and constraints
- **Delegates & Events**: Event-driven programming and callbacks
- **Lambda Expressions**: Inline functions and functional programming
- **LINQ Basics**: Query expressions and method syntax
- **Reflection**: Inspecting types and metadata at runtime
- **Attributes**: Decorating code with metadata
- **Extension Methods**: Adding methods to existing types
- **Nullable Types**: Handling null values safely
- **Tuples**: Returning multiple values efficiently
- **Records**: Immutable data types and pattern matching

## Folder Structure

- `01-Explanation/` - Detailed explanations of advanced features
- `02-Examples/` - Complex code examples

## Prerequisites

- Strong understanding of OOP concepts

## Key Takeaways

- How generics provide type safety and reusability
- Understanding delegates as function types
- Leveraging LINQ for elegant data manipulation
