# Object-Oriented Programming (OOP)

Master the four pillars of OOP: Encapsulation, Abstraction, Inheritance, and Polymorphism.

## Topics Covered

- **Classes & Objects**: Creating and instantiating classes
- **Encapsulation**: Access modifiers (public, private, protected, internal)
- **Properties & Fields**: Auto-properties, getters, and setters
- **Inheritance**: Base classes, derived classes, and the base keyword
- **Polymorphism**: Method overriding, virtual methods, abstract classes
- **Interfaces**: Contract definition and implementation
- **Constructors & Destructors**: Initialization and cleanup
- **Static Members**: Static classes, methods, and properties

## Folder Structure

- `01-Explanation/` - In-depth explanations of OOP concepts
- `02-Examples/` - Real-world code examples

## Prerequisites

- Familiarity with C# Fundamentals

## Key Concepts

- Understanding the difference between classes and objects
- When to use inheritance vs. interfaces
