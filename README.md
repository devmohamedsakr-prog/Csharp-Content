## 🎯 Quick Start

Our repository is designed for hands-on learning. Every topic follows a simple **3-step process**:

1. 📖 **Read** `01-Explanation/` to grasp the core concepts.
2. 💻 **Run** `02-Examples/` to see the code in action.
3. 🛠️ **Practice** by modifying the code yourself!

> [!TIP]
> **New to C#?** Start right at [01-Fundamentals](./01-Fundamentals) and work your way down the list!
