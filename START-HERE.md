## 🎓 How to Study

### Focused File Approach
Each explanation folder has numbered files (01, 02, 03...). Study them in order:

```
1. Open 01-Fundamentals/01-Explanation/01-Data-Types.md
2. Read the entire file
3. Review code examples
4. Try examples yourself
5. Move to 02-Operators.md
6. Repeat
```

### Interview Prep Approach
```
1. Pick a topic (e.g., LINQ)
2. Read topic README
3. Read explanation files (if available)
4. Read interview Q&A
5. Answer questions without looking
6. Compare with provided answers
```
