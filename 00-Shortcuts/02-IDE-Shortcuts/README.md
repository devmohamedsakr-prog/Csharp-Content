## 💡 How to Use

1. Search (Ctrl+F) for the action you want
2. Find the keyboard shortcut
3. Memorize the most frequently used ones
4. Refer back as needed

---

## 🎯 Most Common (All IDEs)

| Action | VS | VS Code |
|--------|----|----|
| Save | Ctrl+S | Ctrl+S |
| Open File | Ctrl+O | Ctrl+O |
| Find | Ctrl+F | Ctrl+F |
| Replace | Ctrl+H | Ctrl+H |
| Undo | Ctrl+Z | Ctrl+Z |
| Redo | Ctrl+Y | Ctrl+Shift+Z |
