# Web Development with C#

Build web applications using ASP.NET and ASP.NET Core.

## Topics Covered

- **ASP.NET Core Basics**: Project structure and setup
- **Controllers & Actions**: Handling HTTP requests
- **Views & Templating**: Razor syntax for rendering HTML
- **Routing**: URL patterns and route configuration
- **Dependency Injection**: Built-in DI container
- **Middleware**: Request processing pipeline
- **Authentication & Authorization**: Securing your application
- **Models & Data Binding**: Working with form data
- **API Development**: RESTful API design with ASP.NET Core
- **Configuration**: appsettings and environment variables
- **Error Handling**: Global exception handling

## Folder Structure

- `01-Explanation/` - Web development concepts
- `02-Examples/` - Sample projects and code snippets

## Prerequisites

- Strong C# fundamentals
- Understanding of HTTP and web concepts

## Getting Started

1. Create your first ASP.NET Core project
2. Build a simple web application
3. Develop RESTful APIs
4. Implement authentication
