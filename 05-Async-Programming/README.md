# Asynchronous Programming

Learn to write responsive applications using async/await patterns.

## Topics Covered

- **Async Basics**: Understanding asynchronous operations
- **Async/Await**: Modern async patterns with async/await keywords
- **Tasks & Promises**: Task<T>, TaskCompletionSource<T>
- **Cancellation**: Using CancellationToken for cancellation
- **Exception Handling**: Try/catch with async code
- **Task Composition**: Task.WhenAll, Task.WhenAny, Task.Run
- **ConfigureAwait**: Performance optimization in libraries
- **Synchronous Wrappers**: Converting async to sync (carefully)
- **Concurrent Operations**: Running tasks in parallel
- **Deadlock Prevention**: Avoiding async pitfalls

## Folder Structure

- `01-Explanation/` - Async programming concepts and patterns
- `02-Examples/` - Real-world async/await examples

## Prerequisites

- Understanding of delegates and callbacks
- Basic knowledge of threading concepts

## Common Patterns

- Async CRUD operations
- Multiple concurrent API calls
- Progress reporting with async operations
