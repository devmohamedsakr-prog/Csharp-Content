# C# Fundamentals

Learn the core building blocks of C#, including syntax, data types, operators, and control flow.

## Topics Covered

- **Variables & Data Types**: Understanding primitive types (int, string, bool, etc.)
- **Operators**: Arithmetic, logical, comparison, and assignment operators
- **Control Flow**: if/else, switch statements, loops (for, while, do-while)
- **Methods**: Function definitions, parameters, return types, and scope
- **Arrays & Collections**: Lists, dictionaries, and basic collection operations
- **String Manipulation**: Working with strings, formatting, and parsing

## Folder Structure

- `01-Explanation/` - Detailed explanations of each concept
- `02-Examples/` - Practical code examples demonstrating the concepts

## Getting Started

1. Start with data types and basic syntax
2. Move through control flow structures
3. Practice with methods and functions
4. Explore collections and array operations
