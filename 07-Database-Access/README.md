# Database Access

Master data persistence with Entity Framework and SQL Server.

## Topics Covered

- **ADO.NET Basics**: Low-level database access
- **Entity Framework Core**: ORM framework fundamentals
- **DbContext**: Configuring and using the context
- **Entities & Models**: Defining data models
- **Migrations**: Version control for database schema
- **Querying Data**: Retrieving records with EF Core
- **Creating & Updating**: Insert and update operations
- **Deleting Data**: Remove records from database
- **Relationships**: One-to-many, many-to-many, one-to-one
- **Lazy vs Eager Loading**: Performance optimization
- **Raw SQL**: When to bypass LINQ
- **Connection Strings**: Configuration and security

## Folder Structure

- `01-Explanation/` - Database concepts and best practices
- `02-Examples/` - Sample code and database patterns

## Prerequisites

- Understanding of relational databases
- C# fundamentals and OOP

## Key Concepts

- Understanding Entity Framework as an ORM
- Relationships and foreign keys
- Performance optimization with loading strategies
- Connection pooling and performance
