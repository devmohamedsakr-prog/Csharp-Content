# Search & Replace

Keyboard shortcuts for searching and replacing in VS and VS Code.

## Find Operations

| Action | VS | VS Code |
|--------|----|----|
| Find | Ctrl+F | Ctrl+F |
| Find Next | F3 | Enter |
| Find Previous | Shift+F3 | Shift+Enter |
| Find in Files | Ctrl+Shift+F | Ctrl+Shift+F |
| Find All References | Shift+F12 | Shift+Alt+F12 |

## Replace Operations

| Action | VS | VS Code |
|--------|----|----|
| Replace | Ctrl+H | Ctrl+H |
| Replace Next | Ctrl+Shift+1 | Ctrl+Shift+1 |
| Replace All | Ctrl+Alt+Enter | Ctrl+Alt+Enter |
| Replace in Files | Ctrl+Shift+H | Ctrl+Shift+H |

## Search Options

| Action | Shortcut |
|--------|----------|
| Match Case | Alt+C |
| Match Whole Word | Alt+W |
| Use Regular Expression | Alt+E |
| Toggle Search Details | Ctrl+Shift+J |

## Quick Find

| Action | VS | VS Code |
|--------|----|----|
| Quick Find | Ctrl+F3 | Ctrl+L |
| Find Symbol | Ctrl+T | Ctrl+Shift+O |
| Go to Line | Ctrl+G | Ctrl+G |
| Go to Declaration | Ctrl+; | Ctrl+K, Ctrl+D |

## Find All Occurrences

| Action | VS | VS Code |
|--------|----|----|
| Select All Occurrences | Ctrl+Shift+Alt+J | Ctrl+Shift+L |
| Add Selection | Ctrl+D | Ctrl+D |
| Skip Occurrence | Ctrl+K, Ctrl+D | Ctrl+K, Ctrl+D |

## Incremental Search (VS Code)

| Action | Shortcut |
|--------|----------|
| Open Incremental Search | Ctrl+F, then type |
| Next Match | Enter |
| Previous Match | Shift+Enter |
| Close Search | Escape |

## Advanced Regex

```
\b\w+\b        Match word boundary
\d+            Match digits
\w+            Match word characters
^\s*$          Match empty lines
[a-z]{3}       Match pattern
```
