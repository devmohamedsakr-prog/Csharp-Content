# Design Patterns

Understand proven solutions to common programming problems.

## Topics Covered

- **Creational Patterns**: Object creation mechanisms
  - Singleton: Single instance across application
  - Factory: Object creation abstraction
  - Builder: Complex object construction
  - Prototype: Cloning objects

- **Structural Patterns**: Object composition and relationships
  - Adapter: Interface compatibility
  - Bridge: Abstraction from implementation
  - Composite: Tree structures
  - Decorator: Adding responsibilities dynamically
  - Facade: Simplified interface
  - Proxy: Placeholder for another object

- **Behavioral Patterns**: Object interaction and responsibility
  - Observer: Event notification system
  - Strategy: Interchangeable algorithms
  - Command: Encapsulating requests
  - Iterator: Traversing collections
  - Template Method: Algorithm skeleton
  - State: Behavior based on state

## Folder Structure

- `01-Explanation/` - Pattern explanations and use cases
- `02-Examples/` - Real-world pattern implementations

## Prerequisites

- Strong understanding of OOP
- Design Principles (SOLID)

## Learning Approach

1. Understand the pattern's intent and structure
2. Study real-world use cases
3. Practice implementing the pattern
4. Learn when and when NOT to use each pattern
