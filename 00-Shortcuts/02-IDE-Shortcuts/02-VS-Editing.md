# Visual Studio - Editing

Keyboard shortcuts for code editing in Visual Studio.

## Selection & Deletion

| Action | Shortcut |
|--------|----------|
| Select All | Ctrl+A |
| Select Line | Ctrl+L |
| Select Word | Ctrl+Shift+Right Arrow |
| Delete Line | Ctrl+Shift+Del |
| Delete Backward | Ctrl+Backspace |
| Delete Forward | Ctrl+Delete |

## Line Operations

| Action | Shortcut |
|--------|----------|
| Cut Line | Ctrl+X |
| Copy Line | Ctrl+C |
| Paste | Ctrl+V |
| Duplicate Line | Ctrl+D |
| Move Line Up | Alt+↑ |
| Move Line Down | Alt+↓ |
| New Line Above | Ctrl+Shift+Enter |
| New Line Below | Ctrl+Enter |

## Comment & Format

| Action | Shortcut |
|--------|----------|
| Toggle Comment | Ctrl+K, Ctrl+C |
| Uncomment | Ctrl+K, Ctrl+U |
| Format Document | Ctrl+K, Ctrl+D |
| Format Selection | Ctrl+K, Ctrl+F |
| Auto Format | Ctrl+Shift+P |

## Indentation

| Action | Shortcut |
|--------|----------|
| Increase Indent | Tab |
| Decrease Indent | Shift+Tab |
| Smart Indent | Ctrl+K, Ctrl+I |

## IntelliSense & Snippets

| Action | Shortcut |
|--------|----------|
| Complete Word | Ctrl+Space |
| Parameter Info | Ctrl+Shift+Space |
| Quick Info | Ctrl+K, Ctrl+I |
| Insert Snippet | Ctrl+K, Ctrl+X |
| Surround With | Ctrl+K, Ctrl+S |

## Multi-Line Editing

| Action | Shortcut |
|--------|----------|
| Add Cursor | Ctrl+Alt+Click |
| Add Next Occurrence | Ctrl+D |
| Select All Occurrences | Ctrl+Shift+Alt+J |
