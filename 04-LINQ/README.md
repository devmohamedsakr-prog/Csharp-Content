# LINQ (Language Integrated Query)

Master query operations for collections and data sources.

## Topics Covered

- **Query Syntax**: Using query expressions
- **Method Syntax**: Fluent API for queries
- **Standard Query Operators**: Where, Select, Join, GroupBy, etc.
- **Filtering & Projection**: Selecting and transforming data
- **Aggregation**: Sum, Count, Average, Min, Max operations
- **Sorting & Ordering**: OrderBy, ThenBy, Reverse
- **Set Operations**: Union, Intersect, Except, Distinct
- **Partitioning**: Take, Skip, TakeWhile, SkipWhile
- **LINQ to Objects**: Working with in-memory collections
- **Deferred Execution**: Understanding query laziness

## Folder Structure

- `01-Explanation/` - LINQ concepts and best practices
- `02-Examples/` - Practical LINQ query examples

## Prerequisites

- Understanding of delegates and lambda expressions
- Familiarity with collections

- Understanding deferred execution
- When to use eager evaluation
